par(r1,r2)

This small yet powerful function was originally written by my friend Erwin Baert. It can be used to reduce two elements in parallel when you are not interested in the current through any of them. It will ease the work for the simulator and reduce the time used to get the answers. This program will work fine even if both entered resistances are zero.

Input data is typed inside the (). Enter two values of resistors, inductors or impedances you have conected in parallel. Value may be numeric or symbolic.

Output data is returned to the answer area. The answer is the equivalent value of the elements.
