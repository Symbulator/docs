thevenin(cir,node1,node2)

This is a tool designed to find the Thévenin and Norton equivalents of the given circuit cir, as seen from node1 and node2. One of these two nodes may be ground.

Input data is typed inside the parenthesis, and consist of a circuit and two nodes. Once you run the program, you have to specify two parameters. If you are aware that your circuit is passive, choose Passive in the first; otherwise, leave Auto-Detect.  In the second, select if you want the values to be found using direct current, alternating current or frequency domain analysis.

When running the thevenin() tool, you should not include a test source: the tool handles both active and  passive circuits.

Output data is the Thévenin voltage vth, Thévenin impedance zth, and the Norton current ino.
