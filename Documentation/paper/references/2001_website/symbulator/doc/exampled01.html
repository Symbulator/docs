D01 AC analysis: Symbolic values - tricky problem

Question. A circuit consists of a resistance in serie with a capacitance. What are their values if a voltage of 240V r.m.s., 200Hz is applied, the current taken from the supply is 2A with a phase angle of 53.1 degrees? (Note: This current is 1.2 + 1.6*i in rectangular form.). No image is given.

Solution:

Solving this problem by hand may be a pain in the hand (or somewhere else). Solving it with Symbulator is just a pleasure! First step, symbulate the circuit:

sq\ac("e1,1,0,240.*sqrt(2); r1,1,2,r; cx,2,0,c",2*Pi*200.)

                Done

Second and last step, ask for the values that fit the current you're given. This is the tricky part:

solve(real(ir1)=1.2 and imag(ir1)=1.6,{r,c})

                r=101.8 (in ohms) and c=5.86E-6 (in faradays)
