absang(r+i*x)

This small yet powerful function was originally written by my friend Erwin Baert. It can be used to see the polar expression of a rectangular value, when the RAD angular mode is set (RAD is set automatically by Symbulator's simulation apps).

The input data has to be typed inside the (). Enter a rectangular complex expression. Values may be numeric or symbolic.

Output data from the program is returned in the answer area. The answer is value in polar form.
