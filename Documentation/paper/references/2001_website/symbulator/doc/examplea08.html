A08 DC analysis: Ideal OpAmp problem

Question. Given the following circuit, find voltage in out node of OpAmp.

Solution:

Clean symbolic variables.

DelVar r1,r2,vin

Label nodes and elements.  Define variable cir containing circuit description. I used this description:

"e1,1,0,vin; r1,1,2,rr1; r2,2,3,rr2; o1,0,2,3" àcir

Simulate this circuit using direct current analysis.

    sq\dc(cir)

Now ask for the voltage by typing:

v3

Answer: The answer obtained is the right one.
