Software: RPN

Last updated: September 24, 2000.

Author's name: Lars Frederiksen

Description: RPN is an interface program which lets you operate a TI89 or TI92+ calculator using an RPN interface, instead of the normal algebraic interface. RPN is a stack-based interface, which is often faster to use than algebraic entry, especially for complicated expressions. RPN is an acronym for reverse Polish notation, which describes the method used to enter operators and operands. RPN has been written for TI calculator users who prefer an RPN interface, or for those who want to learn to use RPN.

The version 2.022 features the following changes since previous version 2.021:

  1. Solved problem with expressions containing "when()" returned from functions (RPN mode only).

  2.  Added "when" to Math\Test menu.

  3. Added special code made by Zeljko Juric, and rebuilt by Lars, in an attempt to avoid TI protection scheme on HW 2 calculators.
