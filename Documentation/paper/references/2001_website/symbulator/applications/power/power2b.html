Power Examples

P-2b. easytran() tool: Transformer fraction of load for highest efficiency

Question. A transformer with 500KVA, 2300/208V, 60 Hz, had the following results in tests:

Test Voltage in V Current in A Real power in W Side measured
Open circuit 208 85 1800 Low voltage
Short circuit 95 217.4 8200 High voltage

Find the highest efficiency of the transformer, at power loads of 1.0 and 0.8 lagging, along with the load fractions to get these efficiencies.

Solution. The easytran() power tool is also designed for this kind of problems. The first step is to run the tool and provide all the information that it requests.

scs/easytran()

The first data asked is the alfa relation between high and low voltage. You can enter it either as a number or as a cocient. We entered 2300/208.. Placing a dot after the number prevents the calculator of using exact manipulation, since in this case floating point is the apropiate. Then the program prompts for the information about open circuit test: select low tension and enter 208., 85. and 1800. in their respective spaces, and press Enter. Then the program prompts for the information about short circuit test: select high tension and enter 95., 217.4 and 8200. in their respective spaces, and press Enter. After this, the program provides the different impedances used to describe the equivalent circuit of the transformer. This impedances are shown in the IO area and also stored in variables. Press Enter until the next dialog box appears.

Then, the program focuses on the load. A drop-down dialog box appears, asking you to choose the type of data you know about the load. In our case, we know the monophasic power, voltage, fp and percent of load. Therefore, we choose the second option: S1 + VLN + fp. After this, the program prompts a dialog box, where you must enter the values of these known variables. Supose we wish calculate the answers for FP=1.0. For this load, input 5E5, 208., 1.0, lagging (or leading, its the same for fp=1.0) and 100. It is important to use 100% of load. At this point, the program displays in the IO area and also stores in variables the phasorial values of S, V, I and Z that match the requested fp and percent. Press Enter until the next dialog box appears.

Now, the program is getting ready to simulate. It requests the value of the source: input 2300. and press Enter. After this, the program simulates the equivalent circuit of the transformer, with the specified source as input and the calculated load. This takes about 12 seconds, until it starts showing answers.

The program shows a lot of answers we don't need in this problem.  The last answer is the one we want, which is the percent of actual load (actual meaning at 100% load and current FP) you need to use to get the greatest efficiency at the given power factor: 47.8%. Just as it appears in the text book. Press enter and the program goes back to the Home display. All answers are stored in variables. Also, the data you introduced is stored, so that the next time you run the program, it will appear already written in the spaces. This saves a lot of time, specially in problems like this one, in which you have to calculate several times almost the same thing, but with few things changing. Now, run the program again and leave all values just as they are, changing just one: the load percent. Input the load percent you received as answer the last time, this is 47.8. Now, take note of the efficiency that the program will show as answer in the IO area. This is the highest efficiency of the transformer at FP=1.0. (BTW, the highest effienciy at FP=1.0 is also the highest efficiency overall). The answer is 98.2%, which is right. (Ignore the comment the program makes at the end, which indicates a new load percent - near to 100% - of actual load for highest efficiency, since you already have the highest efficiency.)

Repeat the same procedure, using in the first round all values the same but the value of FP=0.8 lagging and 100% of load. You'll get 48.0% as the fraction of load to use to get the highest effieciency at that FP. Do the thing again, changing the percent to 48.0 and you'll get the highest effienciency at that FP: 98.1% of efficiency.

These are the right answers! Isn't that easy?
