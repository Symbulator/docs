load()
by Roberto Pérez-Franco

This is a very useful stand-alone tool to get a load which satisfies some given conditions for simulation.

You input data in the program using request areas and dropdown menus. The input data of load() is the data you shall know from a complex load in a circuit, whether triphasic or monophasic. This is, the magnitude of aparent power |S| or real power |P|, voltage |V|, the power factor and the percent of load. You have to input this data and specify whether the power factor is lagging or leading.

You receive output data from the program when the program shows it in the IO area. It also stores it in variables. It is the phasorial S, V, I and Z that fits the specified entry data you give to the program.

Some power examples ilustrate its use.
