Symbulator Q

Symbulator's final version is Q. This version runs in TI-89 and equivalent calculators with AMS 2.0x or higher. It requires the latest DiffEq by Lars Frederiksen, which is version 2.06.

[April 16, 2003] - Symbulator Q updated to built 030416. Small detail changed, nothing important. Seems to run fine in AMS 2.08.

[November 18, 2002] - The first four chapters of The Symbulator Book, the complete documentation for this award-winning software, are available in the instructions area.

Killed
Bugs

[November 18, 2002] - I have fixed the only known bug left in Symbulator Q. It was 1.3 years old. Most of you didn't even knew about it. It only showed up in circuits such as the following:

sq/tr("j1,0,1,sin(t),0;r1,1,0,1,0"):ij1

In the old version, you would see that the current in j1, e.g. ij1, has a value in the domain of s. This only happened with the current of current sources in TR analysis of circuits which trigger the Impala mode. Now I have fixed this bug. As far as I know, nodoby knows of another bugs in the Symbulator. If any shows up, please let me know.
Did you know?
January 9, 2001 - 13h40m

Symbulator runs faster if the circuit description you enter contains only exact values. This means that a circuit with values like 1/3 will run faster than a circuit with values like 0.333.
January 03, 2000 - 01h03m

As far as I know, the fastest platform you can give to Symbulator is this one: a TI-89 hardware 2 with AMS (OS) 2.0x installed, with 180KB free in RAM and with Symbulator and DiffEq correctly archived.
