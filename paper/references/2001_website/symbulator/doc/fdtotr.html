fd_to_tr(function of s)

This small function applies DiffEq's ilaplace() to the input function, using s as default independent variable. Therefore, it takes a function in frequency domain, and returns a function in time domain.

Input data is a function of frequency, for example, the answer of a frequency domain analysis FD.

Output data, which is returned to history, is a function of time.
