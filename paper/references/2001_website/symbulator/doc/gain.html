gain()

This small yet powerful function is to be used with two ports devices, to calculate the voltage gain, current gain, power gain and entry impedance of the device.

Input data is typed in a dialog box presented by the tool when it is runned. You enter the voltage in node 1, the input current in node 1, the voltage in node 2 and the input current in node 2.

Output data is displayed in screen and stored in variables. Voltage gain is stored in variable gv, current gain in gi, power gain in gp and entry impedance of the device in zin.
