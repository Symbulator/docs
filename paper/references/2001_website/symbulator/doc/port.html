port(cir,node1,node2)

This is a tool designed to find the parameters of the two-port equivalent of the given circuit cir, as seen from these two terminals: node1 and ground, and node2 and ground.

Input data is typed inside the parenthesis, and consist of a circuit and two nodes. Once you run the program, you have to specify if you want the parameters to be found using direct current, alternating current or frequency domain analysis. You have to choose the type of parameters you which, among admitance, impedance or hybrid. You are also asked to provide a name for the port.

Output data is the set of four parameters, which are stored in variables according to the name of the port and the type of parameters..
