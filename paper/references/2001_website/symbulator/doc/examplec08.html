C08 DC analysis: Find H parameters of net containing a biport with H parameters

Question. Find the four new h parameters for the net composed of a biport with parameters h11=9, h12=-2, h21=20, h22=0.2, and a resistance in serie with: a) the input, b) the output. No image is provided.

Solution a):

1a) Label nodes and elements. Define a variable containing circuit description. I used this description:

"r1,3,1,1; hp,1,2,0"-> cir

Now store the values of parameters. Since we named the biport as hp, the variables we must store are hp11, hp12, hp21 and hp22.

9 -> hp11 : -2 -> hp12 : 20 -> hp21 : 0.2 -> hp22

2a) Run the ports tools, specifying the terminal nodes, which are 1 and 2.

    sq\port(cir,3,2)

Now the program displays a dialog box, in which you have to specify the desired parameters (which you set to h), give a name to the parameters (s is a good name, for p is already in use) and specify the analysis you want to perform (in this case DC). When done, press Enter. The process is complex, so you have to wait some time. After a while, the calculator displays...

                    Done

3a) Since your parameters are h and their name is s, the answers are stored in the following variables: hs11, hs12, hs21 and hs22. Ask for them:

hs11

                    10

hs12

                    -2

hs21

                    20

hs22

                    0.2

Answer a): The parameters obtained are the right ones.
