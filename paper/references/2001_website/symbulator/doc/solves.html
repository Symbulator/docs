solves()

This powerful program allows you to solve a set of equations - whether complex or not -, and stores after that, it displays all the answers and stores them in variables. It is based in the Symbulator core's technology.

Input data is typed in a dialog boxes presented by the tool when it is runned.

In the first dialog gox, you enter the equations and the unknown variables. Example of the input format:

Equations: x+y+z-t=3 and t*z-y-2x=5

Unknowns: {x,y}

Notice that Unknowns are entered between {}. In the equations above, it is obvious that z and t must be known values. The program asks us if we want to use conditional equations, this is to say values that we already know, like z and t. The program also asks us if we want to solve equations as real or complex ones. If we decide to use conditional equations, a second dialog box asks for the definition of any given value, and the name of any given value. Example of the input format:

"When" Equations: t=2 and z=1.3

"When" Unknowns: t,z

Notice that "When" Unknowns are NOT entered between {}. 

Output data are the answers, which are stored in variables and displayed in the screen.
