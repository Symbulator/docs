P-2a. easytran() tool: Transformer tests, eficiency and voltage regulation at different fractions of load

Question. A transformer with 500KVA, 2300/208V, 60 Hz, had the following results in tests:

Test Voltage in V Current in A Real power in W Side measured
Open circuit 208 85 1800 Low voltage
Short circuit 95 217.4 8200 High voltage

Fill the following table:

Load Loss in copper in kW Loss in iron in kW % of voltage regulation % of efficiency
25% @ FP=1        
50% @ FP=1        
75% @ FP=1        
100% @ FP=1        
125% @ FP=1        
25% @ FP=0.8 lagging        
50% @ FP=0.8 lagging        
75% @ FP=0.8 lagging        
100% @ FP=0.8 lagging        
125% @ FP=0.8 lagging        

Solution. The easytran() power tool is designed for this kind of problems. The first step is to run the tool and provide all the information that it requests.

scs/easytran()

The first data asked is the alfa relation between high and low voltage. You can enter it either as a number or as a cocient. We entered 2300/208.. Placing a dot after the number prevents the calculator of using exact manipulation, since in this case floating point is the apropiate. Then the program prompts for the information about open circuit test: select low tension and enter 208., 85. and 1800. in their respective spaces, and press Enter. Then the program prompts for the information about short circuit test: select high tension and enter 95., 217.4 and 8200. in their respective spaces, and press Enter. After this, the program provides the different impedances used to describe the equivalent circuit of the transformer. This impedances are shown in the IO area and also stored in variables. Press Enter until the next dialog box appears.

Then, the program focuses on the load. A drop-down dialog box appears, asking you to choose the type of data you know about the load. In our case, we know the monophasic power, voltage, fp and percent of load. Therefore, we choose the second option: S1 + VLN + fp. After this, the program prompts a dialog box, where you must enter the values of these known variables. Supose we wish to start calculating the answers for the first load: 25% at fp 1.0. For this load, input 5E5, 208., 1.0, lagging (or leading, its the same for fp=1.0) and 25. At this point, the program displays in the IO area and also stores in variables the phasorial values of S, V, I and Z that match the requested fp and percent. Press Enter until the next dialog box appears.

Now, the program is getting ready to simulate. It requests the value of the source: input 2300. and press Enter. After this, the program simulates the equivalent circuit of the transformer, with the specified source as input and the calculated load. This takes about 12 seconds, until it starts showing answers.

The first answer it shows you is the Power Input, provided by the source; for the load we described it is 1.261E5 Watts. Then, the Power Output, consumed by the load, which in this case is 1.238E5 Watts. Press Enter and the program will display the loss in Fe, 1790 Watts; and the loss in Cu, 515.1 Watts. Press Enter and the program will present the % of efficiency, 98.19%; and the % of voltage regulation, 0.4763%. The last answer given is the percent of actual load (actual meaning the Z you are using now at the fp you are using now, not necessarly the 100% nominal load at FP=1.0) you need to use to get the greatest efficiency at the given power factor: 186.4%. Press enter and the program goes back to the Home display. All answers are stored in variables. Also, the data you introduced is stored, so that the next time you run the program, it will appear already written in the spaces. This saves a lot of time, specially in problems like this one, in which you have to calculate several times almost the same thing, but with one thing changing: load percent. That's why load percent value is automatically returned to a value of 100%.

So, we fill the first row of the table, with rounded values:

Load Loss in copper in W Loss in iron in kW % of voltage regulation % of efficiency
25% @ FP=1 0.515 1.79 0.48 98.2

To fill the rest of the table, just run the program again and press Enter several times until you reach a value you want to change (normally, the load percent and/or the load percent). Change just the values that are new. You'll find the rest of the values (and drop-down selections) intact, just as you left them the last time you ran the program, and that's how they'll remain. Do it for the rest of the loads. We did it and here are our results, rounded to three digits:

Load Loss in copper in kW Loss in iron in kW % of voltage regulation % of efficiency
25% @ FP=1 0.52 1.79 0.48 98.2
50% @ FP=1 2.03 1.78 0.90 98.5
75% @ FP=1 4.50 1.78 1.33 98.3
100% @ FP=1 7.97 1.77 1.79 98.0
125% @ FP=1 12.3 1.76 2.25 97.7
25% @ FP=0.8 lagging 0.47 1.77 0.88 97.9
50% @ FP=0.8 lagging 1.89 1.75 1.77 98.3
75% @ FP=0.8 lagging 4.23 1.74 2.67 98.5
100% @ FP=0.8 lagging 7.50 1.73 3.58 97.4
125% @ FP=0.8 lagging 11.6 1.71 4.52 97.5

These are the right answers! By hand, filling the whole table would have taken hours. With easytran(), it is matter of 12 minutes.
