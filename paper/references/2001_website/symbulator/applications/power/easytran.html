easytran()
by Roberto Pérez-Franco

This powerful tool interacts with SCS dc() simulator, and load() and testranf() tools (which should be in the same folder).

The input data is a combination of input data of load() and testranf(). You have to specify also the value of the source.

The output data is a combination of output data of load() and testranf(). You also receive the losses in the transformer, its voltage regulation and its efficiency, and the fraction of load you need to get the highest efficiency.

Some power examples ilustrate its use.
